# TOTA-Solid-Waste-Dashboard

An interactive **R Shiny dashboard hosted by Posit Connect Cloud** that brings together publicly available solid waste data for the Thompson Okanagan region.

The dashboard was developed by the **Thompson Okanagan Tourism Association (TOTA)** to support solid waste management reporting for the **UN Tourism International Network of Sustainable Tourism Observatories (INSTO)**. This dashboard contributes to ongoing efforts to better understand the relationship between solid waste and tourism in the Thompson Okanagan Region.

## Dashboard

**Live App:** https://tota-solid-waste-dashboard.share.connect.posit.cloud/

## Features

* Disposal Rates - per capita, total tonnes disposed per year across regions.
* Organic Waste - facilities in the tourism region that accept organic waste and what type of waste is accepted.
* KPIS, interactive charts, maps, and historical comparisons.
